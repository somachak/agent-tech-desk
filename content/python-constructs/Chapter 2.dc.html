Tutorial §4.9. After a * in the parameter list, callers must pass those arguments by keyword. That prevents silent swaps — e.g. treating a percent as a function label.

Keyword-only parameters make dangerous arguments explicit at the call site.

Formulator bench helper: build a phase row. pct is keyword-only; function defaults to 'emollient'.

add_to_phase('A', 'Glycerin', pct=3) works. Passing 3 positionally after ingredient raises TypeError. Call add_to_phase for Phenoxyethanol in phase C at 0.8% with function='preservative'.
add_to_phase(phase, ingredient, *, pct, function='emollient') — callers must write pct=.

*args (any name after *) collects extra positional arguments into a tuple. Useful when the number of tags varies per event.

*tags packs zero-or-more positionals into a tuple — no manual list building at the call site.

**kwargs collects leftover keyword arguments into a dict. Open-ended metadata without changing the signature every sprint.

Glass Box traces: kind is fixed; tags and meta flex with the event.
**meta is the open bag for product=, phase=, latency_ms=, and future fields.

Combine: required kind, variable *tags, open **meta. Return a single event dict the Glass Box panel can append.

log_assistant_event(kind, *tags, **meta) → {kind, tags, meta}. Capstone logs accept_draft before building the card.
