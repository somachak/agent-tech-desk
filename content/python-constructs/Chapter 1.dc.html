Official Tutorial §4.8. In Cosmetic AI Assistant, the same formatting rule must run after every accept draft: INCI name plus mass %. A named function is the contract — not copy-pasted f-strings in three UI surfaces.

One helper, many surfaces: recipe card, notebook paste, formulations library preview. List three places in Formulaite that would call the same format_inci_line helper.
Functions name a reusable computation. Formulaite uses them for recipe-card text the assistant shows after accept.

Syntax: def name(params): then an indented body. Parameters are local names. return exits with a value; without it, Python returns None.

Defining Functions — parameters, body, return. We skip the Fibonacci demo and format real INCI lines instead.
def introduces a function; arguments bind to parameters; return sends a value to the caller.

A docstring is a string literal as the first statement in the function body. It documents the contract for humans and for help(). Keep it short and precise — what goes in, what comes out.

Add a one-line docstring to a helper that returns total_pct from a list of ingredient dicts.
Docstrings live in __doc__. Write them for every public Formulaite helper you expect another engineer (or LLM) to call.

Canonical line format for recipe cards: {INCI} {pct:.1f}%. Coerce with float so ints from JSON still render with one decimal.

Coco-Glucoside 12%, Glycerin 3%, Phenoxyethanol 0.8% — typical mild bodywash actives / humectant / preservative.
format_inci_line(name, pct) is the atomic formatter. Everything else composes it.

Compose: walk a list of ingredient dicts and return a list of formatted strings. This is what the assistant UI renders after accept.

Given the four-row draft, output must be four lines ending in % with one decimal place.
build_recipe_card_lines maps rows through format_inci_line. Capstone will feed it from FormulaDraft.as_recipe_lines().
