Tutorial §4.9.6. A lambda creates a function from a single expression — no def block, no statements. Ideal for short key= callables.

Lambdas cannot contain statements (no assignment, no loops). Reach for def when logic grows.
lambda params: expr — anonymous one-liner function returning expr.

sorted(iterable, key=fn) calls fn on each item and sorts by those results. The original objects keep their identity; only order changes.

Pass a callable to key=. Lambda is the usual short form for dict field access.

Descending mass % on the shelf: negate the percent so larger values sort first.

Sort the same rows ascending by pct with a lambda (no reverse=True).
key=lambda r: -r['pct'] ranks high-actives first for the formulator.

When two rows share a %, sort alphabetically by INCI. Return a tuple from the lambda — Python compares left to right.

key=lambda r: (-r['pct'], r['inci']) — required Formulaite shelf ranking key.

Inspiration Studio ranking: banned rows sink; among keepers, descending % then name. One lambda, three-part key.

rank_candidates uses (banned, -pct, inci). Capstone may sort before building the recipe card.
