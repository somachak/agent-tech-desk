Tutorial §9. A class defines a type; __init__ runs when you construct an instance. self is that instance — attributes hang off it.

class + __init__(self, …) + self.attr. Methods are functions that take self first.

Ingredient(inci, pct, function) — one shelf / draft row as an object instead of a loose dict.

Objects beat anonymous dicts once methods and invariants appear. Construct Ingredient('Glycerin', 3, 'humectant') and print its pct.
Ingredient holds inci, pct, function — the Formulaite material noun.

A named bag of ingredients. Prefer items=None then list(items or []) — never a mutable default argument.

FormulaPhase(name, items) with total_pct() over its ingredients.

The accepted assistant draft: product name plus ordered phases. total_pct() should approach 100 for a finished formula (demo totals are partial water-free sketches).

FormulaDraft(product, phases).total_pct() sums every phase.

Flatten the object graph into the same recipe-card strings Chapter 1 produced from dicts.

Four lines + total=16.2% for the Gentle Wash sample.
as_recipe_lines() is the OO bridge to the recipe card UI and the Capstone.
